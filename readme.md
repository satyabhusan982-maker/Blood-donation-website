BloodSetu – Blood Donation Website
Technologies: HTML5, CSS3, Bootstrap 5

- Developed a responsive blood donation website to connect blood donors with people seeking blood.
- Designed user-friendly sections including Home, Donor Registration, Blood Requests, Blood Banks and Contact.
- Created an attractive landing page with a navigation bar, hero section, donation information and emergency blood request cards.
- Used Bootstrap grid, utility classes and custom CSS to build a structured and responsive user interface.
- Organized website assets and styling into separate project files for easier maintenance.
