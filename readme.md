#  BloodSetu – Blood Donation Website

**BloodSetu** is a blood donation awareness website designed to connect blood donors with people who need blood. It provides a simple and user-friendly interface to encourage blood donation, spread awareness, and help users find nearby blood banks.

##  Project Overview

BloodSetu aims to make blood donation information more accessible and encourage people to become regular blood donors.

##  Features

- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Blood Donation Awareness:** Promotes the importance of donating blood.
- **Become a Donor:** Encourages visitors to register as blood donors.
- **Find Nearby Blood Banks:** Provides a section to explore blood bank information.
- **Urgent Blood Requests:** Displays blood requirements to raise awareness.
- **How It Works:** Explains the blood donation process.
- **Modern UI:** Clean layout with attractive sections and visual elements.
- **Navigation:** Easy access to different sections of the website.

##  How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/satyabhusan982-maker/Blood-donation-website.git
   ```

2. Open the project folder:

   ```bash
   cd Blood-donation-website
   ```

3. Open `index.html` in your browser.

4. Alternatively, use the **Live Server** extension in Visual Studio Code.

##  Project Purpose

The main purpose of BloodSetu is to spread awareness about blood donation and create a user-friendly platform where people can explore donor registration and blood bank information.
